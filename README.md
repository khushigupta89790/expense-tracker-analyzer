# 💰 Expense Tracker and Analyzer

A simple Python-based Expense Tracker and Analyzer that allows users to record, view, and analyze their daily expenses.

This project was created as a beginner-friendly Python project to practice core Python concepts such as functions, lists, dictionaries, loops, conditionals, file handling, and CSV data storage.

## 📌 Features

- Add new expenses
- Store expense amount, category, and description
- View all recorded expenses
- Calculate total expenses
- Find the highest individual expense
- Find the category with the highest total spending
- Save expenses to a CSV file
- Load and work with expense data using CSV files
- Simple menu-driven interface

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- CSV
- Git & GitHub
