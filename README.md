# Expense Tracker and Analyzer

A simple Python-based Expense Tracker and Analyzer that helps users record, view, and analyze their expenses.

This project was built as part of my Python learning journey to practice functions, lists, dictionaries, loops, conditionals, and CSV file handling.

## Features

- Add new expenses
- View all recorded expenses
- Store expense amount, category, and description
- Calculate total expenses
- Find the highest individual expense
- Find the highest spending category
- Store expense data in a CSV file
- Load previously saved expense data

## How to Run

1. Clone the repository:

   https://github.com/khushigupta89790/expense-tracker-analyzer

2. Open the project in Jupyter Notebook.

3. Open `Expense Tracker and Analyzer Project.ipynb`.

4. Run the cells in order.

5. Use the menu to add, view, and analyze expenses.

## Menu

1. Add Expense
2. View Expense
3. Analyze
4. Exit

## Expense Analysis

The analyzer provides:

- Total expenses
- Highest individual expense
- Highest spending category
- Total amount spent in the highest spending category
